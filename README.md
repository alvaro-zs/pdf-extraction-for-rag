# PDF extraction for RAG

Workspace for testing PDF text extraction for retrieval-augmented generation (RAG).

## Source documents

- [Sources/docsXP](Sources/docsXP/): reference PDF documents.
- [Sources/To_test](Sources/To_test/): selected PDFs and text files for extraction experiments.

The existing text files contain form-feed characters only; they are not usable text extractions yet.

Extraction code and evaluation results will be added as the experiments develop.
